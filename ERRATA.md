# Corrections

Corrections to the book *Git / GitHub* (November 2026 edition) and its Practice Pack.

GitHub changes often. When a screen, button or rule in the book no longer matches what you see, check here first.

## How to report one

Open an issue in this repo with:

- the page number (the number printed at the bottom of the page),
- what the book says,
- what you saw instead, with a screenshot if you can.
